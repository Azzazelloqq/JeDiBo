# Готовые промпты для агентов

Вся работа по редизайну идёт в ветке **`redesign`**. `main` не трогаем до финального решения владельца.
Агенты работают **последовательно**: сначала A, владелец утверждает дизайн, ветка A вливается в `redesign`, потом B.
Каждый агент — в своей ветке/worktree от `redesign` (например, `redesign-a`, `redesign-b`), результат вливается обратно в `redesign`.

## Агент A — переработка текущего визуала

```
Проект JeDiBo (TypeScript + Vite, не Unity). Работай в ветке от `redesign`, не от main.
Выполни задачу A из docs/redesign/TASK-A-redesign.md.
Перед началом прочитай docs/redesign/README.md целиком и загрузи скиллы jedibo-ui и jedibo-pixel-art.
Главное: брутализм остаётся, «хоррор» уходит; новый логотип из docs/redesign/refs/02-logo-guide.png
с сохранением оригинальной формы; текущий подход к пиксель-арту сохраняется; механику не трогать.
Задачу B (свитчер, варианты, Летопись, иллюстрации карт) не начинай.
Проверяй каждую часть в браузере (скилл jedibo-ui).
В конце: скриншоты до/после в docs/redesign/result/A/, docs/redesign/HANDOFF.md для агента B,
и остановись — владелец будет утверждать дизайн и присылать правки.
```

## Агент B — свитчер и варианты экранов (после утверждения A)

```
Проект JeDiBo (TypeScript + Vite, не Unity). Работай в ветке от `redesign` (в ней уже утверждённый
дизайн задачи A), не от main. Выполни задачу B из docs/redesign/TASK-B-variants.md.
Перед началом прочитай docs/redesign/README.md, docs/redesign/HANDOFF.md и загрузи скиллы
jedibo-ui и jedibo-pixel-art. Вариант «в» = утверждённый дизайн A — его вид не меняй.
Текущий подход к пиксель-арту сохраняется, механику не трогать. Проверяй всё в браузере (скилл jedibo-ui).
В конце: скриншоты всех вариантов в docs/redesign/result/B/.
