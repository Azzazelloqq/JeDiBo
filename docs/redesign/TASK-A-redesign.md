# Задача A — переработка текущего визуала

**Цель:** сохранить брутализм (литой бетон, плиты, опалубка, гранит/базальт фигур, жёсткие пиксельные тени, «сок» анимаций), но убрать ощущение хоррора: сейчас почти всё чёрное, фон — кроваво-красный дым, сильная виньетка и ЭЛТ, красный читается как кровь. Плюс новый логотип, новый блик карт и слайдер громкости.

Результат задачи A = вариант **«в» (Текущий)** для всех экранов и база дизайн-токенов для варианта **«а»** задачи B.

Сначала прочитай `docs/redesign/README.md` (правила, владение файлами) и загрузи скиллы `jedibo-ui` и `jedibo-pixel-art`.

Референсы: `refs/10-3d-proto-brutalism.png` (3D-версия: светлое бетонное поле, графитовые и красные фигуры, оранжево-красный знак), `refs/02-logo-guide.png` (фирменный оранжевый `#FF3600`), `assets/card-illustrations-contact.jpg` (иллюстрации: белый / графит / оранжевый — это тоже язык бренда). Текущее состояние: `current/*.jpg`.

## Диагноз: откуда «хоррор»

| Источник | Где | Что делаем |
|---|---|---|
| Фон почти чёрный + красный дым | `render/background.ts` → `MOODS` | Светлее, теплее; дым оранжевый, не кровавый (A3) |
| Сильная виньетка и мерцание ЭЛТ | `#crt` в `main.css` | Сканлайны тоньше, виньетка мягче, мерцание убрать (A3) |
| Панели `slab900` (#1b1b1e) на чёрном | `.slab`, `--tex-slab` в `main.ts` | Панели — средний/светлый бетон с графитовым текстом, тёмный базальт — только акценты (A4) |
| Красный = «кровь» (`blood-*`) | палитра, тени заголовков, ярлыки | Акцент — фирменный оранжевый «сигнал»; тёмно-красный остаётся только для гранитных фигур (A1) |
| Заголовки с тенью `blood-700` + `void` | `.page-head h1` и др. | Тень графитовая, акцент оранжевый (A4) |
| Названия «кровь», «смерть» в CSS-токенах | палитра | Переименовать токены по роли (A1) |

## A1. Палитра «Дневной бетон»

Файл: `src/render/palette.ts` (единственный источник правды). Предлагаемая отправная точка — подбери и выверь на экране, но держи логику ролей:

| Роль | Токен | Было | Стало (ориентир) |
|---|---|---|---|
| самый тёмный (контуры, тени) | `ink` / `void` | #0b0b0c / #141416 | `#1a1918` / `#24221f` (тёплый графит, не чистый чёрный) |
| базальт (рамы, поле, инсеты) | `slab900…500` | #1b1b1e…#55555c | `#2e2d2b … #6a6762` |
| бетон (панели, кнопки) | `concrete600…100` | #5f5c57…#d9d4c9 | `#7d786f … #ebe6db` — основной цвет панелей ≈ `concrete200/300` |
| светлый (фон текста, бумага) | `bone` | #e8e3d7 | `#f4f0e6` |
| **бренд / сигнал** | `signal`, `brand500/400/700` | #ff4a36 | `#FF3600` (логотип), `#ff6a3a` (hover), `#b82600` (кромка) |
| гранит красных фигур | `granite*` (вместо `blood*`) | #2a0707…#e0493a | чуть теплее и светлее, ближе к 3D: `#3a0e08 … #e2502e`; не путать с брендом — бренд ярче и оранжевее |
| Карма | `amber*` | как есть | оставить (тёплое золото хорошо с бетоном) |
| инфо / «хорошо» | `patina*` | как есть | оставить, чуть светлее |

Требования:
- Переименовать `blood*` → `granite*` (фигуры) и завести `brand*` (UI-акцент). Пройти grep по `blood-`, `--blood`, `PAL.blood` и разнести по ролям: UI-акценты → `brand`, фигуры/урон → `granite`.
- Контраст текста ≥ 4.5:1 (основной) и ≥ 3:1 (крупный пиксельный) — проверить для пар «текст/панель».
- `STONE.red` и `STONE.black` (фигуры) — сохранить читаемость на светлом поле 3D-референса: чёрные фигуры = графит, красные = гранит. Поле (`render/board.ts`, `cellTile`) оставить светло-бетонным, рамку — базальт, но не чёрную.
- Обнови раздел «Визуальная система» в корневом `README.md`.

## A3. Фон и ЭЛТ

- `background.ts`, `MOODS`: менее тёмные базовые цвета (средний бетон), «дым» — бренд-оранжевый / янтарь, без кроваво-красного. Пример направления: `menu: a=#3b3935, b=#6e6a63, c=#ff5a1f, heat 0.25`; `game` — спокойнее и светлее меню, чтобы поле читалось; `karma` — янтарь; `win` — тёплый светлый; `lose` — холодный серый, но не чёрный. Виньетку в шейдере ослабить (`smoothstep(0.6, 1.5, r)`), постеризацию оставить (это пиксельность).
- Экспортировать из `background.ts` API для варианта «а» задачи B: `setMood(m)` уже есть; добавить `setBackgroundPalette({a,b,c})` и опцию плавного цикла цветов (`cycle: string[][]`, период 30–60 с) — B будет звать её на меню «а». Реализуй сам механизм, набор цветов подберёт B.
- `#crt`: сканлайны `rgba(0,0,0,0.06)`, виньетка до `0.25`, мерцание по умолчанию выключено. Настройка «ЭЛТ-эффект» остаётся.

## A4. Компоненты

В `main.css` (и генерации фактур в `main.ts`):
- `.slab` — светлая/средняя бетонная плита (`--tex-concrete`), текст `ink`, стяжки опалубки остаются. Вторичные/вложенные поверхности — тёмный базальт с текстом `bone` (инсеты, поле, лог хроники) — для контраста и брутализма «бетон + металл/базальт».
- Кнопки: `btn-stone` по умолчанию, `btn-brand` (новый, вместо `btn-red`) для главного действия, `btn-amber` для Кармы, `btn-dark`. Нажатие с «утапливанием» оставить. Покачивание `--wob` уменьшить вдвое — меньше «нервозности».
- Заголовки страниц: тень `ink`, без красного; акцентная чёрточка/квадрат — бренд.
- `.h-label::before` — квадрат бренд-цвета (вместо кровавого).
- `.tag`, `.toast`, `.pip`, `.kt` (трек Кармы), `.meter` — перекрасить по ролям.
- Иконки «✝ на кладбище» → нейтральная пиктограмма (пиксельная урна/обломки), меньше «смерти» в UI-текстах только там, где это стиль, а не игровой термин (названия карт не трогаем).

## A6. Карты Кармы: плиты и блик

1. `render/cardArt.ts`: тиры — простая = светлый бетон, редкая = бронза/янтарь, роковая = бренд-оранжевый гранит (не кроваво-красный). Рубашка (`sprites.ts → cardBack`) — пиксельный знак логотипа на бетоне.
2. **Блик при наведении** (`ui/card.ts`, `.kcard-shine`). Сейчас: большое радиальное пятно в `screen` + полоса, засвечивает центр и название. Нужно: «свет от лампы по глянцу», в пиксельном стиле, не мешающий чтению.
   - Узкая диагональная **полоса блика** (≈ 3–4 пикселя карты шириной, под углом ~115°), позиция вдоль диагонали зависит от курсора (`--mx/--my`), края полосы ступенчатые — квантовать на сетку пикселя карты (`--s`): использовать `repeating-linear-gradient` с шагом `calc(var(--s) * 1px)` или маску из пиксельного паттерна; никакого гауссова пятна.
   - Плюс тонкая подсветка **кромки**, обращённой к свету (верх/лево при курсоре сверху-слева) — 1 пиксель карты, `bone` с alpha ≈ 0.5.
   - Плюс 1–2 «искры» (2×2 пикселя карты) на рамке, на мгновение при входе курсора.
   - Интенсивность ≤ 0.3 в режиме `soft-light`/`overlay` для иллюстрированной лицевой стороны и ≤ 0.35 `screen` для иконочной. Блик **не ложится** на плашку названия и строку тира: плашка выше по z-index, либо маска только по окну иллюстрации и рамке.
   - Наклон 3D уменьшить (сейчас до 22–26°) до ~10–12° — меньше искажение текста.
   - Должно одинаково работать для режима «Иконки» и «Иллюстрации» (иллюстрации добавляет B; заложи, что лицевая сторона может быть `<img>`/canvas во всю карту с плашкой названия снизу).
   - Уважать `prefers-reduced-motion` и настройку «Тряска экрана» — без анимации искр.
3. Проверить на `scale` 2 (сетка колоды), 4 (детали), 3 (рука/оверлей Кармы).
